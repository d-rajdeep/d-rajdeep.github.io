Before you choose

Frequently asked questions.

Not sure which plan fits? Send a short description of what you need and we can map it to the right scope.

Ask a question
Can a plan be customised?

Yes. The listed packages are starting points. Additional pages, workflows, integrations and design requirements can be added to the scope and quoted before work begins.

Will I be able to update the website myself?

The Silver plan is a static one-page website. Gold and Diamond include an admin panel for the selected content and functionality agreed for the project.

Does Diamond include a customer mobile shopping app?

Diamond includes a basic Android admin companion app for store operations, such as viewing orders and updating order status. A separate customer shopping app would need its own scope and quote.

What does “24×7 security” mean?

The website is built with security essentials in mind, including appropriate SSL setup where supported, safer form handling and sensible configuration. Always-on human monitoring and incident response are ongoing services and are scoped separately.

Are renewals and third-party charges included?

Diamond includes the domain and hosting for the first year. Renewal after year one, payment gateway transaction charges, paid APIs and other third-party subscriptions are separate unless explicitly included in the written project scope.
